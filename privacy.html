Privacy policy

Last updated: 27 October 2026

Command Centre is a personal tool used only by its owner, Connor Robinson. This policy covers the Google user data it accesses.

What data it accesses

With the owner's consent, Command Centre reads Gmail messages, Google Drive files and Google Calendar events using read-only scopes (gmail.readonly, drive.readonly, calendar.readonly), plus the owner's basic profile and email address.

How the data is used

The data is used only to help the owner organise his own schedule, travel, household and finances, for example summarising upcoming events or finding a receipt. The app never sends email, never modifies or deletes files or events, and never shares data publicly.

Storage and sharing

OAuth tokens are stored on servers the owner controls. Data the app reads may be processed by an AI model provider (through OpenRouter) to produce summaries for the owner. No data is sold, used for advertising, or shared with anyone else.

Command Centre's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.
